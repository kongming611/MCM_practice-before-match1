# 问题一论文手交接稿（现阶段）

本文档只给可由题目数据和既定方案支持的论证框架，不填写任何模型分数、企业风险值或最优信贷策略数值。

## 1. 题型判断

第一问是“发票数据驱动的违约风险预测 + 利率下客户接受行为拟合 + 固定预算信贷组合优化”，不是单纯综合评价或静态排序。前半段回答谁的历史违约倾向较高，后半段回答固定资金贷给谁、贷多少、采用什么利率。

## 2. 总体流程

发票质量审计 → 有效/作废/退货/零额分流 → 企业月度聚合 → 21项可解释发票特征 → 弹性网Logistic风险值 → A/B/C单调流失率曲线 → 固定预算混合整数优化 → 参数和观察窗口敏感性分析。

## 3. 为什么先聚合到企业级

违约标签属于企业而非单张发票。把同一家企业的发票明细随机分到训练和测试两侧会让模型“见过”测试企业，形成严重泄漏；明细量大的企业还会被重复加权。按统一月份窗口聚合后，一家企业只占一行，风险标签、预测对象和决策对象才一致。

## 4. 为什么主模型选弹性网Logistic

附件1只有123个企业级样本且违约类别较少，复杂模型容易过拟合。Logistic直接输出风险倾向；L1与L2组合既能抑制经营规模、集中度等共线性，又保留较稳定的变量组，系数方向便于解释。模型仍须用企业级重复分层交叉验证检验，不能仅凭“可解释”宣称有效。

## 5. 为什么信誉评级不进入主违约模型

评级是银行人工先验，且附件2没有该字段。若把评级直接加入主模型，得到的高分可能主要复制人工判断，不能证明发票特征具有迁移能力。主模型只使用两附件共有的发票特征；评级可用于评级—违约列联验证、独立校准敏感性检查、附件3贷款定价及D级拒贷规则。

## 6. 为什么不能只用准确率

违约样本占比较低时，把多数企业都判为不违约也可能得到较高准确率，却无法识别真正高风险企业，也不能说明概率是否可信。主报告应使用PR-AUC评价少数类排序，用Brier分数和LogLoss评价概率质量；ROC-AUC仅辅助，并展示PR、ROC和校准曲线。

## 7. 信贷优化模型

记企业风险值为 \(\hat p_i\)，评级 \(g_i\) 在利率 \(r\) 下的流失率为 \(L_g(r)\)，接受概率为 \(A_i(r)=1-L_{g_i}(r)\)。在附件3利率点 \(r_k\in[0.04,0.15]\) 上，\(x_{ik}\) 表示是否按该利率放贷，\(s_{ik}\) 为额度（万元）。给定LGD \(\ell\) 和资金成本率 \(c_f\)，最大化
\[
\sum_{i,k}A_i(r_k)s_{ik}\left[(1-\hat p_i)r_k-c_f-\hat p_i\ell\right].
\]
约束为
\[
\sum_kx_{ik}\le1,\quad 10x_{ik}\le s_{ik}\le100x_{ik},\quad
\sum_{i,k}s_{ik}=B.
\]
D级企业基准设 \(\sum_kx_{ik}=0\)。由此同时得到是否放贷、额度与利率；加息既提高名义利息，也会提高流失率，因此不是风险越高利率越高的简单规则。

## 8. 当前缺少的参数

| 缺口 | 现阶段写法 |
|---|---|
| 问题一年度预算 \(B\) | 作为万元参数，不能给唯一额度表 |
| LGD/回收率 | 仅写参数化预期损失，并等待敏感性运行 |
| 银行资金及边际成本 \(c_f\) | 作为年化参数，不虚构净利润 |
| 违约发生日期和观察期 | 风险值称为历史违约倾向，不称严格一年期PD |
| “固定总额”是必须投完还是额度上限 | 主规格按完全分配；另做上限口径敏感性检查 |
