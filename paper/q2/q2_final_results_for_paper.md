# 问题二最终结果（论文手交付稿）

本稿的最终策略只读取当前分支生成的 `data/processed/q2_risk_rating_scores.csv`、附件3已验收的A/B/C流失曲线和 `outputs/q2/tables` 中的正式求解结果。302家企业没有真实违约标签，以下“风险”“评级概率”“接受概率”“预期损失”和“预期净收益”均是模型与参数情景下的条件结果，不是现实结果的保证。

## 1. 问题二建模闭环

同口径企业特征迁移 → 弹性网Logistic历史违约倾向 → 有序Logistic四级评级概率 → Label Spreading交叉检查和不确定性标记 → A/B/C概率混合客户流失率 → 贷款接受概率 → 1亿元名义预算MILP → 预算口径、风险分位数、LGD、资金成本和不确定性规则敏感性。

主场景的接受概率为

\[
A_i(r_k)=\sum_{g\in\{A,B,C\}}\pi_{ig}[1-L_g(r_k)],
\]

单位名义授信的情景净边际收益为

\[
u_{ik}=A_i(r_k)[(1-p_i)r_k-c_f-p_i\ell],
\]

其中 \(p_i\) 是优化表中 `risk_used` 的历史违约倾向代理，\(\ell\) 是LGD情景参数，\(c_f\) 是资金成本率。D级概率质量不分配D级流失曲线，也不向A/B/C重新归一化。

## 2. 1亿元主场景MILP

金额字段单位为万元（`amount_unit=10000_CNY`），因此主场景 `budget_10k=10000` 等于名义授信1亿元。预注册主场景参数为：风险变体=`mean`（使用 `risk_mean`）、LGD=0.50、资金成本率=0.03、预算口径=`nominal_equality`、D级概率拒贷阈值=0.80、不确定性额度上限50万元、最低/最高额度10/100万元。利率只能取附件3的29个实际观测点。

## 3. 主场景策略汇总

164家获贷企业中，128家受不确定性额度上限约束而获贷50万元，36家获贷100万元。选定利率分布为：9.85%共31家、10.25%共15家、10.65%共5家、12.25%共39家、14.25%共74家。138家未获贷，其中D概率规则拒贷12家、高不确定性降额后未被优化选择118家、其余优化未选择8家。

上述分组来自 `data/processed/q2_credit_strategy.csv` 的正式策略字段；正文不展开302家逐企业表，完整策略表放在附录A。
