## 2. 建模假设与运行默认

| 参数/规则 | 当前值 | 分类 | 说明 |
|---|---:|---|---|
| 归一化尺度 `c` | 40 个百分点 | 建模假设/运行默认 | `S_h=clip(max(0,-g_h)/40,0,1)`；不是官方阈值 |
| 风险放大系数 `rho` | 0.25 | 建模假设/运行默认 | 风险乘数 `1+rho*D`；敏感性检验0.10/0.50 |
| 场景倍数 | identity 0、light 0.5、medium 1、severe 1.5 | 建模假设/运行默认 | severe 的1.5不是官方情景概率 |
| 风险裁剪 | `eps=1e-6` | 数值实现默认 | 保证风险处于 `[0,1-eps]` |
| unknown 主策略 | `max_known_S`，`S=0.8825` | 建模策略假设/运行默认 | 145家 unknown 使用已知行业最大压力；不是这145家真实属于住宿餐饮 |
| unknown 敏感性 | `p50_known_S` | 敏感性登记值 | 只作为替代政策场景，不改变中心策略 |
| LGD | 0.50 | 运行默认/建模假设 | 未由Q3外部回收数据校准；敏感性0.30/0.70 |
| 资金成本率 | 0.03 | 运行默认/建模假设 | 敏感性0.02/0.04 |
| 预算 | 10000 个 `10k CNY` 单位=1亿元 | 题设/模型约束实现 | 严格名义等式，不是预期实际放款上限 |
| 单户额度 | 10～100万元 | Q2约束复用 | 高不确定性登记上限50万元；D概率阈值0.8拒贷 |
| 行业上限 | 无 | 运行默认 | HHI仅为结果摘要，不是行业配额约束 |
| robust 定义 | 场景风险逐户最大值 | 建模定义 | 当前单调设置使 robust=severe；不是独立观测证据 |

上述 `c`、`rho`、`lambda`、LGD、`c_f` 和 unknown 政策均应在论文中写成“建模假设/运行默认”。不能标记为官方参数、估计值或已通过外部验证的团队结论。

## 3. Q2 风险与复用边界

- Q2 的 `main_risk_score` 是历史发票行为的相对违约倾向；302家目标企业没有外部真实违约标签，因此 Q3 不把它命名为 PD，也不声称有一年期违约概率校准。
- Q3 仅覆盖风险列；Q2 评级概率、D 级阈值、A/B/C 流失曲线、候选利率、额度上下界和不确定性规则保持不变。`customer_churn` 是客户流失/接受关系，不是违约率。
- identity 必须逐行等于 Q2 风险；robust/severe 相同来自场景单调性。两项契约 `PASS` 证明的是实现一致性，不是预测准确性。
- fixed-Q2-under-robust 是模型隐含对照：固定 Q2 的决策、利率和额度，只将 robust 风险代入经济量。它不能解释为“现实中沿用Q2策略的实际损失”。

## 4. 行业映射限制

行业映射只使用企业名称的确定性关键词。当前145家为 unknown，其中56家是通用名称 `个体经营E###`，5家规则冲突，84家低特异性或未匹配；11类映射是粗粒度政策类别，不是企业登记行业、供应链暴露或真实营业收入结构。

名称中的“科技”“服务”“材料”等泛词不会自动赋予行业；因此 unknown 数量较大是有意保守的规则结果。论文应报告 unknown 比例和主策略，而不能把规则标签当作观测协变量或因果解释。

## 5. 尚待团队确认的事项

各项现有计算证据、替代参数结果和建议确认口径已集中整理在 [Q3人工确认包](q3_manual_confirmation_packet.md)。以下复选框仍必须由相应责任人确认，不能由自动门禁代签。

以下项目目前不能因 contract `PASS` 而勾选完成：

- [ ] 团队确认 `c=40`、`rho=0.25` 和三档场景倍数是否作为正式题解假设；责任人：建模负责人；原因：当前仅为登记的建模默认。
- [ ] 团队确认 unknown 使用 `max_known_S` 是否符合风险偏好；责任人：业务/建模负责人；原因：P50 只做敏感性，主策略尚无外部行业信息验证。
- [ ] 团队确认 LGD=0.50、资金成本率=0.03 的解释及题解写法；责任人：财务/建模负责人；原因：当前没有 recovery 或融资成本观测校准。
- [ ] 团队人工复核行业映射中的边界名称；责任人：数据负责人；原因：关键词规则不能取代企业登记资料。
- [ ] 团队确认“回顾性外部压力标尺”是否允许用于题目叙事；责任人：论文负责人；原因：2020Q1含3月，晚于 Q2 发票窗口。

## 6. 当前不可验证或未建模的事项

1. 没有持续期/期限校准：Q3 没有把单季度增长映射为违约持续时间、恢复路径或宏观传导系数。
2. 没有外部违约标签验证：无法据此报告 ROC-AUC、Brier、真实 PD 校准、实际损失或银行利润。
3. 没有回收率、担保品、行业上限或相关性模型；单户风险乘法也不捕捉共同冲击相关性。
4. 没有把官方分行业 GDP 与企业级发票特征做因果估计；行业映射误差和选择偏差未被量化。
5. 单因素敏感性是确定性重算，不是统计不确定性区间；探索性组合不是预测。
6. 固定策略对照、HHI 变化和“策略更稳健”等叙述都是在本模型约束下的隐含量，不能外推到真实授信表现。
